180 PDB files and 180 energy summaries: 12 models for each of the 15 Table 1
targets, built with nominal geometry (rise 3.4 Å, twist 29°) from the
default-parameter inputs.

The naming, sanitization and licensing notes are the same as in
[`../models/README.md`](../models/README.md). Regenerate with:

```bash
FORCE=1 bash ../pipeline/run_table1.sh
```
